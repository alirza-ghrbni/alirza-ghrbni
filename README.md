# Hi, I'm Alireza Ghorbani 👋

M.Sc. student in Computer Engineering and data analyst, based in Istanbul.

My work is in machine learning and computer vision, with a focus on
security-related applications: my thesis applies deep CNNs to violence
detection in video, and I have worked on document forgery detection
with image processing. I am currently moving toward cloud computing,
IoT, and reinforcement learning for smart environment security as my
graduate research direction.

## 🔬 Research Interests
- AI for security and surveillance (violence and criminal activity detection)
- Cloud computing, distributed systems, and IoT
- Fuzzy logic and reinforcement learning

## 📄 Publications

- *Chronological Order Detection of Crossed Pen and Stamp Ink Lines Using Deep Learning* (manuscript in preparation)
